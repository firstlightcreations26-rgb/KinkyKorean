# The Kinky Korean — GitHub Pages Starter

This is the first visual/interactive starter for **The Kinky Korean** diary site.

## Included

- Pink notebook landing page
- "Before You Open My Diary…" free intro
- Entry #001 page
- Handwritten-style diary design
- Archive with locked-page previews
- Daily / Unfiltered / Single Entry pricing cards
- Embedded `🎧 LISTEN` placeholder
- Five-full-voice-entry concept
- Private Message / Private Extras placeholders
- KK Check-In questionnaire
- The Unmasking milestone section
- Tiny Tip Jar at the bottom
- Mobile-friendly layout

## Important

This version is a **front-end prototype**. Payment processing, accounts, subscriber access control, private messaging, real audio uploads, and a real tip system are not connected yet.

Do not put private customer information or payment credentials in this repository.

## GitHub Pages

1. Create a new GitHub repository named `kinky-korean`.
2. Upload all files and folders in this package.
3. In GitHub, open **Settings → Pages**.
4. Set the source to **Deploy from a branch**.
5. Choose your main branch and the `/ (root)` folder.
6. Save. GitHub will provide your Pages address.

Later, the custom domain `kinkykorean.blog` can be connected to GitHub Pages.
